# Playing card images

These 52 PNG images are stored locally so the Card Sorter interface works
without internet access.

Source: [The Public Domain Deck](https://github.com/AustinGabriel/The-Public-Domain-Deck-Public-Domain-and-CC0-Playing-Cards)

The source images were resized from 1500 x 2100 to 500 x 700 pixels for the
web interface. This deck uses flat traditional pips, illustrated court cards,
and an ornamental Ace of Spades.

The assets are dedicated to the public domain under CC0. See `LICENSE` for
details and source credits.
